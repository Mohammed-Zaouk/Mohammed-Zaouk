### 🔒 RedactMZ &nbsp;·&nbsp; Client-Side PDF Redaction Tool &nbsp;·&nbsp; <a href="https://www.redactmz.com">redactmz.com</a> &nbsp;·&nbsp; <a href="https://github.com/Mohammed-Zaouk/RedactMZ">Repo</a>
